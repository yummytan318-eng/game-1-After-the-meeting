# 散会以后 · After the Meeting

一款可在手机和电脑浏览器游玩的中文职场悬疑推理游戏。你受命复核一份意外死亡报告。能写进最终结论的每一项判断，都得经得起证物和证词的核对。

## 案件从这里开始

周四，20:58。清洁工夏姐推开衡星科技 B2 层的防火门，发现 HR 负责人 WHY-K 倒在楼梯平台上。平时靠着档案柜的小脚凳，这晚横在门口。初报只写了一句：“取档案时意外跌落。”

在此之前，公司里出现过两份绩效表。同一名员工，在一份里是“项目超额完成，奖金待核”，在另一份里却成了“连续两季不达标”。两份表都留了下来。它们与楼梯间发生的事有没有关系，由你调查。

## 开始游戏

1. 在电脑上打开仓库里的 [index.html](./index.html)，点击 GitHub 文件页面右上方的下载按钮（Download raw file）。
2. 双击下载好的 `index.html`，用浏览器打开即可。画面、剧情和游戏逻辑都在这一个文件里，无需安装软件或启动服务器。
3. 读完序章，点击 **进入 B2 现场**。第一步可以看看那张小脚凳，再读一遍初报。

## 怎么调查

| 游戏界面 | 你可以做什么 |
| --- | --- |
| 调查现场 | 阅读场景上方的“当前疑问”，点击画面中发亮的物件。手机上也可以直接点场景下方的行动按钮。 |
| 证物 | 检查过的物件会自动记入这里。听到新说法时，可以翻回原始记录，核对时间、位置和措辞。 |
| 人物 | 回看人物资料，带着已经找到的证物去询问相关人物。同一句证词，和现场细节放在一起，可能会有不同的解释。 |
| 结案 | 调查推进后解锁。除了作出判断，还需要分别选出支持现场时间线和幕后指控的证据。 |

卡住时，可以先打开右上角的 **调查手册**，重读序章或查看证物。想自己寻找可疑之处，也可以在手册里勾选 **关闭目标光效**。

## 存档与继续

游戏会在当前浏览器自动保存调查进度。想保留某次询问前的现场，可以点右上角的 **存档**，另存到三个手动存档位中的一个。重新开始会覆盖自动存档，想重玩的玩家可以先手动留档。下次请使用同一设备和浏览器，从原来的位置打开游戏。

## English overview

*After the Meeting* is a Chinese-language workplace mystery for mobile and desktop browsers. An HR manager is found dead in a basement stairwell. The initial report calls it an accident. As the investigator assigned to review the case, you inspect the scene, question witnesses, and decide which evidence supports your reconstruction. To play locally, download `index.html` and open it in your browser.
